# Foil Studio 复古小卡工坊

[打开在线工作室](https://hurrygoooodjob.github.io/foil-studio/) · [直接试用亚克力卡面](https://hurrygoooodjob.github.io/foil-studio/?material=acrylic)

上传自己的照片，挑选复古卡框、表面材质和异形贴纸。拖动卡片试光，保存透明 PNG，或将倾转、粒子消散导出为四秒循环视频。

用浏览器打开同目录的 [index.html](index.html) 即可体验。照片和默认素材都在本机处理。将此文件夹完整复制到另一台电脑后也可以离线打开。

## 玩法

点击工具栏的「上传照片」，或在「卡面」面板选取照片。在「调整照片」里拖动照片、调整缩放，随后可在「卡框」面板切换六款边框。六款共用原照片、取景、卡名和编号。

工作区是一张可无限平移的单卡画布。拖动空白处、使用手型工具，或按住空格拖动来平移。滚轮围绕指针缩放，手机支持双指操作。「找回卡片」恢复适应尺寸。浮动面板可以收起。画布缩放改变观察距离，照片缩放改变卡框里的取景。

## 根据原图生成

「随图生成」提供套色版画、折光棱镜和原图回纹。默认从卡面照片提取风格，也可点「上传参考图」单独指定配色和纹理来源。版画从明暗和纹理方向安排色块、网点，棱镜依据颜色和对比度绘制分面，回纹把图像中的明暗轮廓拼成连续花纹。点「使用卡面照片」可恢复跟随照片。

## 上传边框贴纸

打开「贴纸」并点击「上传贴纸素材」，可多选 PNG、WebP 和 JPG。拖住素材的可见部分定位，用面板调大小、角度和层级。方向键可以微调位置，按住 Shift 可以十倍步长移动。若素材是整张透明边框，点「适配整卡」即可居中按比例铺开。贴纸编辑模式下也可直接向画布拖入图片。

贴纸在卡框、照片和表面材质上方。把贴纸拖到卡边，只要一部分还连在卡上，露在外面的部分也能继续抓住拖动。PNG 会随外轮廓扩大画幅，四秒视频自动将整个造型纳入画面。对于有白色底的文字或图案，可选「去除白底」去掉与图像边缘相连的白色；再次关闭可恢复原图。透明 PNG 或 WebP 可直接保留镂空。

选中一张贴纸，在「图层样式」调整描边的颜色和宽度、外发光的颜色和范围，以及投影的颜色、模糊和水平或垂直偏移。混合模式和不透明度按图层分别保存。上传的照片、参考图和贴纸均在本次页面会话中使用。

## 切换表面材质

在「卡面 → 卡片材质」选择表面，可直接拖动卡片试光或调节「材质强度」。六款卡框都可使用这四种表面，切换时照片取景、卡框、夹层和贴纸位置都会保留。

- 原版印刷显示卡框原来的箔纹、纸张或丹宁质地。
- 半透明薄膜让框边透出更多背景，照片区域保留较浓的印色。保存成透明 PNG 后，可将它放在不同底色上观察透光。
- 抛光亚克力带有切面厚边和两条反光，左右倾转时光带会扫过卡面。
- 磨砂透光让照片细节柔化，在表面叠加固定的细颗粒与柔和的光斑。

## 试光与夹层装饰

在「拖动试光」里，横向或纵向拖动让卡片倾转。「摇一摇」会让夹层粒子弹起、翻面，松手后会逐渐落定。「卡片回正」恢复正面视角。

- 银铬典藏卡的切角边框随倾角折射彩光，夹层里是薄金属星片。
- 千禧拼贴卡由报纸、光碟和磁带贴纸组成，夹层里是翻动的糖果纸屑。
- 丹宁应援卡以靛蓝斜纹、缝线和绣章围出照片窗口，夹层里是带孔的半透明珠片。

在「卡面」面板的「卡片材质」里调节镭射强度、夹层装饰数量（0 至 36 枚）或开关「显示夹层装饰」。点击「保存卡面」可导出当前角度、光线与装饰姿态的透明 PNG。试光时聚焦卡面，方向键可倾转，Home 键回正。

## 整卡粒子消散

摆好卡片，点画布动效栏的「粒子消散」。消散从右缘向左蔓延，照片、卡框、贴纸和字迹碎成各自颜色的细尘，向右上方飘走。播放结束后会停留在空场。点「重播消散」可再看一次，点「还原卡片」可继续原来的编辑。隐藏夹层装饰时也能让整张卡消散。

点页面顶部的「导出消散视频」，再点「保存 MP4」。导出的四秒循环由整卡开始，碎散、短暂停留，再聚回原位；画面沿用点下消散时的构图、倾角、反光和夹层。消散期间的「保存原卡」仍可导出完整的透明 PNG。

## 四秒循环视频

上传并摆好照片，点击右上角「导出循环视频」。在弹窗中预览整段动效，点击「保存 MP4」即可下载。视频为 720 × 960 像素、30 帧/秒、4 秒的无声 H.264 MP4。整个页面可离线工作。

成片沿用所选卡框、照片、裁切、卡名、编号、反光强度及粒子设置。卡片从正面向右倾，经过正面向左倾，再衔接到起点。不同夹层材料沿边槽错时滑动与翻面。回到工作台换一款卡框，即可将同一构图导出成另一段循环。文件名包含卡面名称和卡框款式。

倾转视频和消散视频均包含选定的表面材质、框外贴纸及其样式。MP4 会将透光的部分合成在视频背景上。

## 文件与素材

- index.html、studio.css、studio.js 提供界面、上传裁切、姿态控制及 PNG 导出。
- card.js 提供共用的照片绘制与银铬卡框。collage-card.js 和 denim-card.js 分别绘制千禧拼贴卡和丹宁应援卡，frames.js 负责选择款式。
- stars.js 处理三种材料的滑动、碰撞、惯性与三维翻面。
- board.js、board.css 控制画布相机、手势和浮动面板。style-frames.js 提取图像特征并绘制三款联动卡框。stickers.js、stickers.css 处理上传素材的图层、交互和绘制。
- card-materials.js 负责表面透光、亚克力边缘反光与磨砂扩散。sticker-fx.js 合成透明轮廓样式，sticker-cutout.js 可去除贴纸外侧白底。
- dissolve.js 从整卡快照取色，控制原图的逐步剥蚀和碎屑的飞行。工作台和视频共用这一绘制过程。
- portrait.js 内嵌 ASTRA 样卡照片。原图为 NASA 阿波罗 11 号任务 AS11-40-5903，摄影 Neil Armstrong。ASTRA 是演示卡名。[NASA 原片资料](https://eol.jsc.nasa.gov/SearchPhotos/photo.pl?frame=5903&mission=AS11&roll=40)

- loop-scene.js、loop-encoder.js、loop-dialog.js 负责循环构图、逐帧编码和交付界面。浏览器支持时使用原生 H.264 编码，在需要兼容时调用随项目附带的软件编码器。[依赖来源与许可](vendor/NOTICE.md)
